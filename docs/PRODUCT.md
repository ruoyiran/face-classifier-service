# 产品文档

## 产品定位

`face-classifier-service` 是一个私有化部署的人脸原子能力服务。它为手机相册类业务提供稳定的基础能力：人脸检测、对齐裁剪、质量评分和特征向量提取。业务方可以基于这些结果在外部实现人物聚类、人物簇管理、合并拆分、命名和检索。

## 目标用户

- 相册/媒体资产管理系统：需要从本地照片中提取人脸特征。
- 私有 NAS 或家庭媒体服务：需要在本地完成照片分析，不把原图上传到第三方云。
- 研究或非商业项目：需要可复现的开源模型流水线。

## V1 范围

V1 提供以下能力：

- 单图或批量图片上传。
- 人脸检测，返回原图坐标系下的 `bbox_xyxy` 和 `det_score`。
- 人脸对齐，返回 5 点、可选 106 点、仿射矩阵和可选 aligned crop。
- 人脸质量分，衡量图片对识别任务的可用性。
- 人脸 embedding，服务端 L2 normalize 后返回。
- Bearer token 认证。
- 可选加密上传和加密响应。
- 可配置 API base path。

## 非目标

V1 不提供以下能力：

- 人脸聚类和人物簇命名。
- 人物库、向量库或相似度阈值策略。
- 照片去重、相册同步或云端任务调度。
- 活体检测、年龄、性别、表情、属性识别。
- 前端 UI。
- 商用授权处理。

## 成功标准

- 在私有 GPU 环境中稳定启动，并能通过 `/readyz` 表示模型是否就绪。
- 外部业务可以通过 `/v1/faces/analyze` 一次拿到检测、对齐、质量分和 embedding。
- 输出 embedding 对同一模型和同一 `preprocess_id` 保持兼容。
- 明文和加密接口行为一致；加密接口不泄露明文人脸结果。
- 无人脸图片返回空 `faces`，不会作为异常处理。

## 业务边界

服务只负责原子能力，不对业务结果做判断。人物分类效果由外部业务的聚类算法、阈值标定、人工纠错、增量更新和数据质量共同决定。
